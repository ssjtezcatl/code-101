# code-101 · Terminal Survival

Practice work for **CODE 101** in my self-study course: Bash, Git, and GitHub (alongside freeCodeCamp's Relational Database course). This is the first repo in my public portfolio.

## Layout

```
week-01-bash/          navigating the shell, files, pipes
week-02-bash-scripts/  variables, loops, small scripts
week-03-git/           commits, branches, merges
week-04-github/        remotes, pull requests, issues
scripts/               finished scripts worth showing off
```

Each week folder gets a `notes.md` plus whatever scripts I wrote that week.

## How I work

- Small commits with clear messages, pushed on build days.
- Scripts in `scripts/` have a comment at the top saying what they do and how to run them.

Learning to code and red team at the same time, one week at a time. Follow along as more repos show up here.
